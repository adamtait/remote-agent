# Code of Conduct

This project adopts the [Contributor Covenant](https://www.contributor-covenant.org),
version 2.1, as its code of conduct. The full text is available at:

https://www.contributor-covenant.org/version/2/1/code_of_conduct/

In short: we are committed to providing a welcoming, harassment-free experience
for everyone who participates in this project, regardless of background or
identity. Be respectful and constructive in issues, pull requests, and all other
project spaces.

## Reporting

To report a concern about participant behavior, contact the project maintainer
privately via GitHub (open a [private vulnerability report](SECURITY.md) channel
or direct message rather than a public issue). Reports will be reviewed and
handled confidentially.
